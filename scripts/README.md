# scripts｜永久停用 / 仅保留迁移说明

按用户 2026-11-07 决议，**正式卡不包含任何**原卡 MVU、酒馆助手脚本、正则美化脚本、状态栏渲染、悬浮球、外部 JS 依赖、旧变量初始化或 NSFW 选项。此目录不承载生产中的脚本文件。

历史审计提及的 8 个酒馆助手脚本与 7 个正则是源卡盘点信息，**不得据此重新启用**。

迁移时需将 112 条含 EJS/getvar 的世界书条目、开场占位符和游戏版本条件静态化或按内容选择舍弃；并移除最终卡 `extensions.tavern_helper`、`extensions.regex_scripts`、`[InitVar]`/MVU 更新器等脚本化内容，避免空壳残留。

世界书普通关键词触发、条目启停和双重防递归属于原生世界书功能，不属于被取消的脚本。

见 [004 方案](../docs/004_铃寄宿单线与无脚本静态卡_方案修订_v1.0.md) 与 [QA-003](../qa/003_单线与无脚本迁移QA_v1.0.md)。
