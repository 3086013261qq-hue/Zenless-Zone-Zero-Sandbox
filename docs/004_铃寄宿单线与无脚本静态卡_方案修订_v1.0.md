# 004｜铃寄宿单线 × 无脚本静态角色卡｜正式方案修订 v1.0

生效日期：2026-11-07。用户确认优先于 001/002 中的旧 MVU/脚本/双分支设想；保留原始审计报告作为源文件盘点历史。

## 一、冻结的设计决策

1. **佩洛伊斯唯一寄宿者：铃（Belle）**；**非寄宿者：哲（Wise）**。法厄同仍由兄妹共同组成；铃为本卡主时间线的寄宿载体，不代表把哲从人物或共同剧情中删除。
2. 只生产一条连续的**铃寄宿版**时间线；不保留“哲寄宿版”作为可选分支，最终静态正文不出现切换用 `getvar`。
3. 不再制作/移植 MVU、状态栏、悬浮球、酒馆助手脚本、正则美化/替换脚本、外部 JS 运行时、剧情变量引擎、NSFW Helper / NSFW Char Stage / NSFW 开关。不能为“兼容”悄悄装回原系统。
4. **保留咩咩全栈必需的静态世界书功能**：蓝灯常驻、绿灯关键词触发、双重防递归、人物/能力同源、时间线按卷开关、地点按需启用。上述机制不得依赖旧外部脚本。
5. 原卡 122 对（122 详细 + 122 简版）是**内容候选池**，不是两个要同时装卡的剧情线，也不等于只截取与寄宿有关的六章；保留与铃寄宿主线兼容的共同剧情及必要前置，逐卷整理，最终每事件只保留一个启用文本版本。
6. 采用 **YYYY年MM月DD日 + 卷内 A/B/C** 等编号，独立上下卷分别从 A 开始；保留原事件标题，连续事件日期合理递进。没有官方明确日期时明确标注“卡内编年锚点”并全局自洽，**不要将源卡 `world.date=2077-03-15` 当作官方事件日期**。
7. 从原卡到新卡的迁移必须保留映射与来源追踪；原卡原版正文、旧脚本与旧 PNG 不进入未经授权的 public 仓库。

## 三、无脚本迁移风险

原卡中 **112 条**世界书条目含 `getvar(` / EJS 模板标签，其中包含 `char` 56、`npc` 32、`fac` 9、`lore` 1、`main` 2、`story` 6、`lite story` 6；这些**都不能未经转换直接装卡**。

此外原卡开场含 `<StatusPlaceHolderImpl/>`，旧初始化变量含 `NSFW Helper`、`NSFW Char Stage`、`游戏版本` 和日期字段；这些是旧引擎内容，不能进入最终卡。

最终装卡前核查：无 `extensions.tavern_helper`、`extensions.regex_scripts`，无原脚本块、旧变量初始化、外部运行时引入、NSFW 开关和待渲染模板标签；世界书静态触发实际有效。
