- 原卡 `lore:蚀驭` ID 598810 用了「蚀驭柱网络」和极简管线原理。先前018～019与v1.2曾因证据不足而整体排除；现在找到**游戏内「式舆防卫战」的确认文本**，防卫军周期性守卫零号空洞里的式舆以太储留巨构体。**设施存在是官设，不应因原卡误名而完全排除。**
- 官方更新公告使用「式舆防卫战」一词，游戏内教程转录指出保卫「式舆」设施；因此本次只写其储留、危险与防卫职能。所谓城中各家终端一律依某个固定节点直供、储留物必经某条地下管线等，尚未得到逐项交叉确认，正文不写。
- 不改已经冻结的 BLUE-08 经济根设定；普通以太提取/处理链继续由BLUE-08承载。
