## 原卡直接查验及裁剪
- ID429491 原文包含多岗位服务、导航、充电站、面部屏幕与「嗯呢」语言等素材，也将普通邦布的法定权利写得过于笼统。本轮只写可靠的常规工作、任务定制、定期维护与交流方式；**不写普通邦布自动获公民权**。
- ID772490 仅有「相当于邦布专属的特殊互联网络」一句；存在一个专用网络，但其权限、通信协议与控制机制均没有足够原文资料，不能推演。
- ID65506 混合逻辑核心、独立意志、平均以太适性和进食需求。本次以封版 BLUE-05/既有核心 GREEN-05-03 为边界，不把推测的平均以太适性和「无需进食」写成官设。
- 法厄同 H.D.D. 和伊埃斯是特别系统，不是所有邦布都可被远程控制的通用基础设施。
