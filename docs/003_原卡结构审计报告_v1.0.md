## 六、改造推荐的分层与冻结清单
1. **原始层只读冻结**：PNG + 无损 ccv3 JSON + SHA-256 + 本报告；不上传整张带原版权内容的卡到公共仓库，除非确定拥有公开发布授权。
2. **蓝灯**：扮演规则、城市/空洞/以太/通用机制；常驻精简，主设定保持内世界叙述。
3. **绿灯**：从 `lore/fac/item/mob` 按专题拆条，按照双重防递归、低歧义触发、限域触发规则校对。
4. **人物与能力**：主角色与 NPC 分层，女性角色填齐身高/体重/字母罩杯，能力单独且与人物条目同源，遵照原卡设定不杜撰。
5. **时间线**：122 个故事对先建立来源映射与依赖图，再以原著/游戏内先后为准核实与分卷；每卷独立 A/B/C 编号；不把详细/简略双版混装为同一常驻条目。
6. **地点**：71 原地点 + `optional: loc` 条目查重合并；不按商店柜台等细节无限拆分。
7. **界面与脚本**：以新全栈需求重构，但旧有 MVU/正则作为兼容参照，分别测试开场、代码块、更新变量、剧情锚点，明确是否做锁屏/悬浮球（尚未决定）。
8. **最终装配**：固定完整卡 V3 构建流程，校验世界书启用状态、分区标记顺序、脚本实际内嵌、无施工说明混入、每卷上下分开、Android/SillyTavern 实机通过。
