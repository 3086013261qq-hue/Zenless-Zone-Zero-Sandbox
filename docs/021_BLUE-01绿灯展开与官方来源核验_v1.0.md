## 原卡核对结论
- 原卡 `lore:旧文明`（133356）为69字简述；由公开可见的纪录片、存续文化与档案等事实扩写，且与已封版 BLUE-01 的整体生活背景去重。原卡其他版本介绍（735752）仅作连续世界基线，不复制脚本分支和二创划区。
- 原卡 `lore:虚狩`（161827）混有虚狩称号及初代七人等可靠设定，和未经公共证实的“业核、结使、辉金封印、某位角色的授勋时机”等后期秘密。只保留**英雄荣誉、卓越功绩不限武力、旧都至新艾利都的称号传承**，不列初代人物名录、个人秘密及新增授勋事件。
- **不把初代七人误认为现役七个常驻军职**；虚狩不是治安、军事或政府部门的直接统帅身份。
- **旧文明遗存不等于旧都陷落**，也不能凭电影中的神话推导现实存在精灵、吸血鬼等原创物种。
- 无 MVU、旧 EJS、脚本、正则美化、NSFW、旧“游戏版本”切换。
