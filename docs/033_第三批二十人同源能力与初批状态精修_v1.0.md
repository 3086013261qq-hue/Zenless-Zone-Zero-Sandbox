## 原卡与官方来源剔除规则
- 本批仅选择原卡82项中的20个可在[《绝区零》官方网站角色目录](https://zenless.hoyoverse.com/m/en-us/main)逐项核实的官方人物；原卡自拟人物、未核实来源、战力等级及带EJS版本切换的后续剧情不转入正式正文。
- 角色不同工作服、日常身份及心情写进同一人物篇；武器与技能独立但同名触发。原卡外貌字段可在不与官方形象冲突前提下合理补全；女性成年角色采用身高/体重/罩杯工程值，幼态或未成年不作罩杯数字化。
- 敌对组织的历史内幕、角色后期觉醒、个人不为公众知晓的创伤是叙述者背景，不代表所有NPC知晓；人物正文不用自动时间解锁。
- 特别检查：星见雅=六课课长与虚狩荣誉；浅羽悠真罹患以太适性衰竭综合征；扳机双眼失明但具有非视觉感知；仪玄、橘福福、潘引壶属于云岿山；雨果、薇薇安为反舌鸟；柚叶、爱丽丝与真斗属于怪啖屋。
- 先前「星徽·比利」「零号·安比」不另造第二个人物：新增阶段GREEN，原本角色＋基础能力继续保留；铃与佩洛伊斯力量的觉醒也只作独立状态扩展。凯撒代理霸主同理。
