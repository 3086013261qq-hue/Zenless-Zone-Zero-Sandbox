## 二、独立绿灯地点
- 地点条目采用咩咩全栈地点母版 `<地点:名称>` + `介绍:` + `</地点:名称>`，各自独立关键词触发且同时开启双重防递归。
- 空间层次按“城市总貌 → 关键区域 → 必要核心 SITE”逐级辨识，但**只对有独立叙事与空间功能的地点独立建卡**。
- 小商店、同一建筑中的无意义细分、单次提及场景等默认不拆分；多层空间可以在相应地点内解释。
- 独立地点条目仅描述稳定的空间与环境、地理功能、势力归属及已发生的恒定历史；不写具体 NPC 常驻安排、任务导演、进入门槛、能力数值或跨卷剧透。
