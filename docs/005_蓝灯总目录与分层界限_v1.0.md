## 为什么采用九条蓝灯
原卡 73 条 lore 只是主题词条，另有 main 4、fac 29、optional 18 等不同性质条目。直接全常驻会产生过量上下文、剧情过早泄露与来源混杂。
九条按**叙事长期根规则**拆分，围绕“世界格局—灾害—生存—行业—科技—社会—权力—经济—固定主线”九个独立责任面，不按游戏版本拆世界、不直接按源卡分区照搬。

### BLUE-01｜世界格局与新艾利都
- **蓝灯只写：** 旧都灾变之后的新艾利都、仍在运转的都市与末世日常基调；不同剧情阶段在同一世界连续发生。
- **不写/转交：** 详细城市地图、七行政区、具体区域演变、旧都秘闻、虚狩历史与年份数字交给地点/绿灯/时间线。
- **候选绿灯：** 「灾后城市结构与民众认知」、「旧都与重大历史遗留」、「城市风貌与区域生活」。
- **审查重点：** 原卡把1.0/3.0写成互斥模板；‘七大行政区’‘人口百分比’‘百年前’等未经充分独立核验不得直接入蓝灯。
- **对应源卡 ID（仅追溯，非入库批准）：** 735752、613270、133356、126395、161827。

### BLUE-02｜空洞与空间灾害
- **蓝灯只写：** 空洞为不稳定且危险的异常空间，内部空间规律与外界不同；空洞既是灾难也影响社会运行。
- **不写/转交：** 零号空洞、六姐妹、秽息、泄露奇点、芭蕾双子及具体空洞地形归绿灯与地点层。
- **候选绿灯：** 「空洞内部空间和撤离条件」、「伴生空洞及异常空间」、「特殊空洞与后期新机制」。
- **审查重点：** 不将‘所有大空洞皆源自零号空洞’等原卡推断写为已证实世界规则。
- **对应源卡 ID（仅追溯，非入库批准）：** 215863、142987、251574、243976、764051。

### BLUE-03｜以太、侵蚀与以骸
- **蓝灯只写：** 以太资源与侵蚀危险并存；个体存在以太耐受差异，空洞活动具生命风险，以骸是关键威胁。
- **不写/转交：** 以太适性数值评分、疾病病程、特种以骸与敌人抗性、秽息等归机制绿灯/敌人层。
- **候选绿灯：** 「以太适性与暴露风险」、「侵蚀后果与医学处置」、「以骸生态与分类」。
- **审查重点：** 源卡把适性量表写成0–100和50分禁入；尚不能确认是官方通行标准，不直接蓝灯化。
- **对应源卡 ID（仅追溯，非入库批准）：** 266953、56536、173199、582897、72、740063。

### BLUE-04｜空洞行动与绳匠体系
- **蓝灯只写：** 空洞探索依赖信息、路径与组织协同；代理人、绳匠、调查员、盗洞客承担不同职责与社会合法性。
- **不写/转交：** 绳网操作细节、萝卜数据格式、任务佣金、VR玩法、各派具体人员及能力归绿灯/人物层。
- **候选绿灯：** 「绳匠与绳网委托生态」、「调查员、代理人及盗洞客分工」、「萝卜导航与路线变化」。
- **审查重点：** 官方对绳匠的态度与 HIA 执法权要按官方材料核对，避免‘所有从业者都违法’的笼统断言。
- **对应源卡 ID（仅追溯，非入库批准）：** 163717、290820、688475、961723、600322。

### BLUE-05｜邦布与智能科技
- **蓝灯只写：** 邦布是广泛参与生活与空洞行动的智能设备；人工智能、智能构装和各式机具构成城市科技日常。
- **不写/转交：** 禁果测试细则、不同邦布型号、邦布公民权、Fairy、H.D.D.的法厄同专属实现归绿灯/人物/BLUE-09。
- **候选绿灯：** 「邦布的用途与差异」、「智能构装与机器意识」、「智能设备/技术应用」。
- **审查重点：** 原卡对邦布普遍法定权利的措辞可能和‘通过禁果测试取得人格权’相冲突，须区分一般邦布与特定个体。
- **对应源卡 ID（仅追溯，非入库批准）：** 429491、65506、887385、772490、538706。

### BLUE-06｜都市社会与多元族群
- **蓝灯只写：** 城市内人类、希人和其他有差异的居民共同生活；社会保有日常商业文化与个体边界。
- **不写/转交：** 各族生理细节、影视歌曲、具体饮料品牌、固定人口占比及原卡新增幻想种族归绿灯并分来源等级。
- **候选绿灯：** 「希人与城市共居」、「特殊族群资料核查」、「城市文化、媒体与日常服务」。
- **审查重点：** ‘鬼人/吸血鬼/恶魔/精灵’的类别与普遍生理描述须核对官方；‘70%/20%’是源卡说法，未经证实不常驻。
- **对应源卡 ID（仅追溯，非入库批准）：** 321617、724029、285732、500325、448269、742645、977329、659918。

### BLUE-07｜城市治理与势力秩序
- **蓝灯只写：** 新艾利都的市政、治安、防卫、对空机构和企业势力并存，权限与利益关系复杂；法律后果不因主角身份消失。
- **不写/转交：** TOPS成员及控股关系、各派权力斗争、称颂会/街头组织细节交绿灯与组织条目；组织成员交人物层。
- **候选绿灯：** 「市政/治安/军防/对空职权」、「财团、企业及行业组织」、「地下势力与社会冲突」。
- **审查重点：** 原卡对HAND隶属关系表述互相冲突；HIA/HAND/NEPS的正式简称及职能必须以官方资料为准。
- **对应源卡 ID（仅追溯，非入库批准）：** 558920、639159、961723、931536、764065、73253、908496。

### BLUE-08｜以太经济与产业体系

## 来源层级与最小化
1. 官方页面/游戏已证实事实 > 本项目已冻结的明确改编决定 > 原卡二创推断/补充设定（待核）。
2. 官方话术可能是“市政宣传/角色观点”；不能直接当全知客观真理（例如官方宣传‘完全掌控空洞灾害’与具体风险并存）。
3. 原卡时间/地图/人口硬数值和未经官方证明的细节一律标待核；若用户希望保留，可明示作为**卡内原创补充**，而非伪装官方设定。
4. 常驻蓝灯建议单条以简练段落为主；具体长度在逐条精修时结合 SillyTavern 上下文预算确定，不能按原卡字符数原样搬迁。
5. 蓝灯只保持世界约束，不承担角色卡身高/体重/罩杯、能力数值、剧情节点、地理坐标、脚本运行时等独立层责任。

## 单线防泄露策略
- BLUE-09 的固定真相是“铃唯一寄宿，哲非寄宿”；这是幕后连续性约束，**不是**公共世界常识。
- 玩家当前所处日期决定是否已进入寄宿情节；未到该日期角色不凭蓝灯提前拥有未来能力。
- 佩洛伊斯的身份、寄宿发生方式、后续战斗能力与当地 NPC 知情程度须映射人物/能力/时间线，避免整卡开局全员剧透。
- 单线意味着删去哲寄宿分支，不删法厄同兄妹的共同行动和交互。
