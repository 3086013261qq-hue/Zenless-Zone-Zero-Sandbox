## 统一装配口径
- 独立设定条目的`comment`为`核心设定:名称`，在核心设定区使用`insertion_order=302–309`、`position=after_char`；正式装卡需服从母版既有分区阅读顺序。
- 每条`keys`使用表中具体名词及别称；`secondary_keys=[]`，`enabled=true`（不是剧情待开启），`constant=false`、`selective=true`，`use_regex=false`（当前普通字面关键词模式）。
- `extensions.prevent_recursion=true` 与 `extensions.exclude_recursion=true` 同时启用，保持 snake_case 单一规范字段。绿灯已启用≠常驻，只有关键词触发才插入。
- 与母版冲突时以母版具体字段为准，但不得自行恢复MVU、酒馆助手脚本、正则美化或NSFW开关；也不能把旧故事的脚本字段混入。
- 已排除原卡未经官方核实的固定以太适性分值、丁尼现实汇率、全体邦布公民权、蚀驭柱网络、鬼人族权利与种族大战等猜测内容。
