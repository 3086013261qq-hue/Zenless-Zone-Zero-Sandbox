# 019｜取消剧情绿灯默认关闭｜无 MVU 静态世界书修正 v1.0

**生效日期：2026-11-07。优先级高于 018/017 中关于 STORY_GATE_DISABLED 的建议。**

## 一、问题与最终决定

原018曾计划将10条剧情候选以 enabled=false 作为“待剧情发生后自动启用”的GREEN；**没有 MVU、脚本和状态管理器时，这些禁用条目不会因剧情发生自行开启。该方案已撤销。**

正式策略只有两种：
1. **稳定、无剧透的通用设定 → 原生关键词 GREEN：** 实际装配时 `disable=false`（启用），`constant=false`，`selective=true`，`use_regex=false`，并且 `extensions.exclude_recursion=true`、`extensions.prevent_recursion=true`。启用≠常驻，只有关键词命中才插入。所有键仍需后续实测。
2. **有阶段性揭露、角色知情或能力成长 → 不生产“默认关闭的剧情GREEN”：** 移至对应的主线时间线、人物、独立能力，以及必要的地点/道具条目。剧情前不出现这些秘密正文；出现时由时间线事件和角色状态承载。

**关键词不是时钟，也不是通关记录。** SillyTavern 的普通 World Info 不会依据卡内日历或章节状态自动永久切换开关。单纯把某个晚期组织名称放在触发键里，只能说明文字被提及，不意味着该角色已经经历了对应剧情。原定“时间线按卷开关”仍属于静态分卷操作，不能声称自动推进。

- **BLUE-01～09 FROZEN v1.0，一字不改**；无 MVU、无旧 EJS/状态栏脚本、无正则美化、无 NSFW 开关。
