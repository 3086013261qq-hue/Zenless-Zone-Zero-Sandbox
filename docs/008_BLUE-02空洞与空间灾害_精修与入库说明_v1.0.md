## 主题职责
- 空洞为异常球状空间，能够突然出现并侵吞周边事物。
- 内部时空混乱，寻常的方向、距离和路径认知不足以保证安全通行。
- 空洞造成空间侵吞、地区封锁、疏散与探索撤离风险，其根本机理尚有未解。
- 正文采用独立的 `<世界观:空洞与空间灾害>` 标签及世界内叙述，不出现“玩家、AI、游戏版本”等元指令。
