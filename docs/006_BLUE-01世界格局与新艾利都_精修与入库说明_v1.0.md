### 精修差异
1. 明确“已知最后的繁荣大都市”，避免外部无限凭空生成同等大城市；保留“已知”而不宣称绝对不存在幸存聚居地或后期隐藏地域。
2. 分开写世界范围的空洞灾害与旧都随后陷落，避免将两次不同背景的灾难合并；**不杜撰具体年份**。
3. 明确城市的日常社会生活一般发生在空洞之外，但仍面临侵袭和封锁。BLUE-02 负责异常空间地貌，此处只限定基本城市格局。
4. 保留“在空洞危险中开发以太”的经济矛盾，既非征服空洞也非纯废土生存。细化到生产链/机构转入 BLUE-07/08。
5. 直接加入录像带出租店、街机厅、便利店、霓虹与智能机械共存的文化锚点，减少普通末日废土/纯赛博朋克误读。
6. 正文约 **300 个非空白字符**（排除 XML 标签），仍为三段，未扩地点名单、组织系统、游戏版本开关、主线寄宿秘密与 NSFW 内容。
