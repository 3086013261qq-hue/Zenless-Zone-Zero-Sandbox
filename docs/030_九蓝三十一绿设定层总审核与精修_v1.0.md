## 本轮发现与修正
1. **内世界文字污染（P1，已修）：** 原稿部分绿色正文出现「剧情」「玩家界面」「游戏界面」「后期结果」「角色秘密按剧情开启」等编剧/操作指令。现改成都市事实、信息公开范围或实际历史会变化的客观表述。
2. **罗塞塔数据来源（P1，已修）：** GREEN-04-02区分官方机构持有的导航母本与民间收集的路线信息。不能将二者统称为民间可自由获得的罗塞塔母本。
3. **希人概括（P1，已修）：** GREEN-06-02去除把原卡猫薄荷反应类比到整个猫希人族群的陈述，保留个人差异。冻结BLUE-06不变；鬼人全族法律与战争传闻仍排除。
4. **无证据的别称与触发误判（P1，已修）：** 从GREEN-06-06触发词去除原卡误写「利都通讯」（正式报刊是「城市快报」）；从GREEN-08-01去掉未确认的「式舆柱」；从GREEN-08-03去掉原卡存疑的「波引擎」；GREEN-09-01将通用硬盘缩写「HDD」变为较明确的「HDD系统」，正式键「H.D.D.」保留。
5. **剧情内幕与公开组织（持续边界）：** TOPS、狡兔屋、维多利亚家政、白祇重工、卡吕冬之子、奥波勒斯、妄想天使、外环联盟只写组织通识。角色隐私、已发生具体赛事和各卷事件留人物/时间线。
6. **BLUE-09认知分隔（后续装卡必查）：** BLUE-09中佩洛伊斯寄宿、赫利俄斯旧事属于叙述者世界根设定；**不能把蓝灯常驻误解为所有NPC知道秘密**。人物与时间线必须体现每个角色实际已获知的信息。
7. **时序与常驻（后续装卡必查）：** 无MVU。时间线只能按卷手动切换，别写「关闭的绿灯会随剧情自动开启」。不在绿灯写未解锁人物能力。
8. **审查状态：** 非法脚本/EJS/MVU/NSFW不得继承；真实Character Card V3条目未装配、词条命中误触发及双防递归未在Android/SillyTavern实测；不能据此宣称整卡运行PASS。
