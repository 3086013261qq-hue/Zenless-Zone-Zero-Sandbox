## 防误读设计
1. **“萝卜”不等于植物或永久可靠的地图**；会受空洞空间变动影响。
2. **绳匠不是战斗职业的同义词**；其专业核心是导航、信息、引路。不能一律让绳匠独自入洞冲锋，亦不能认定任何绳匠永远不能亲自进洞。
3. **代理人、官方调查员、盗洞客不是一个职业的不同称号**；前线行动、授权调查与擅自入洞有不同身份和法律风险，也可能在具体人物身上重叠。
4. **绳网≠空洞调查协会**：前者是民间匿名委托/情报网络，后者是官方认可的调查组织；不把任何绳网帖都当官方许可证。
5. 民间绳匠的法律灰区与非法工作需要实际任务和许可证判断；不把所有代理人、救援人员笼统写为非法。
