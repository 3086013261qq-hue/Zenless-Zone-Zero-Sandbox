## 必须主动解决的一处原卡内部冲突
原卡 `lore:邦布` (429491) 认为邦布普遍有法定权利，甚至可被简单表述为完整法律人格；但 `lore:禁果测试` (887385) 和游戏内对话把独立意志、禁果测试及法律公民资格分开。**不能照搬原卡“凡邦布都有公民权”的笼统说法。**

根据可追溯的游戏内对话记录（详见下），普通邦布普遍具有个性、情绪和社会互动能力，但这不意味着都通过了禁果测试或自动享有与构装公民相同的法定人格。BLUE-05 使用“**不自动享有公民身份**”避免无限扩大或过度否认其社会权益。个例须按剧情事实核查。

## 分层与防误读
1. **邦布 ≠ 普通家电**：有多样工作、面部显示及音节语言、可表现个性；也不是默认能说流利人话的真人。
2. **邦布 ≠ 智能构装公民**：会说话、具备性格并不能自动推出已通过禁果测试。
3. **智能构装 ≠ 必然人类形貌**：具体身体由原型/剧情定，不能统一改成人脸。
4. **数字智能实体 ≠ 必有机械躯体**：数据空间中的程序智能与实体机器人不同。
5. H.D.D./伊埃斯、Fairy 等法厄同专属细节交 BLUE-09、角色与能力层；邦布网络、禁果测试程序、具体身份权益和构装的电子身体限制交绿灯。
6. 与 BLUE-04 的交叉仅限“邦布可辅助空洞引导”，不重复绳匠/萝卜/委托流程；不增加具体地点或主线时间节点。
