## 本条专门防止的模型误读
1. **希人不是单一兽耳人群，也不等于普通动物变身成人类。** 个体外形介于少量动物特征和兽形构造之间，需按角色设定确认。
2. **希人不是野兽或以骸。** 兽类特征不能据此认定其不会说话、不守法律、不能工作、天然丧失理性。
3. **不同族群不等于职业、性格或能力的固定模板。** 独立人物能力要由其自身条目决定，尤其不能将个别希人的强适性当成所有族群的硬数值。
4. **鬼族存在不代表精灵、恶魔、吸血鬼等传说物种自动成为官方城市居民。** 后者的来源与身份需逐项验证或明确标记原创。
5. **现代都市生活不等于全部居民高度和谐，也不等于处处歧视冲突。** 同时保留消费文化、阶层差异与个体生活。
6. **智能构装体只在此作为共居者出现**；公民权与禁果测试已在 BLUE-05 讲述，不重复法律细则。
