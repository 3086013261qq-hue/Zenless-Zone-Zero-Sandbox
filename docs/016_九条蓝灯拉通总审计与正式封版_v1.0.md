## 五条原稿不动的理由
- BLUE-02 已直接堵住“空洞=地下迷宫”误读，特殊地形后置。
- BLUE-03 已区分以太能源、侵蚀、适性和以骸多种来源。
- BLUE-05 已区分邦布、智能构装与禁果测试，不把所有邦布自动认定为有公民身份。
- BLUE-07 已纠正原卡 H.I.A. 和 H.A.N.D. 下属关系误写，政警军、财团分明。
- BLUE-08 已区分工业能源转化与危险原始以太；丁尼是日常货币但不假设人民币等值。

- 地理：BLUE-01 写城市总体，BLUE-02 写异常空间；**LOCATION-BLUE-00** 只在地点阶段另做一条总分区蓝灯，地点各自为绿灯；目前地点正文未生产。
