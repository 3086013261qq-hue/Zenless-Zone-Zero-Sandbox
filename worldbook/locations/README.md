- 原卡71条 `loc:` 已逐一处理，64个独立地点正文对应68个原卡来源；`外环`和`卫非地半岛`已有地点BLUE，不再重复；`巨洞`是电影，排除地点层。
- 港区海神雕像并入厄匹斯港；`桶之贤者`纠正为光映广场相关垃圾桶地标而非原卡虚构酒吧；贝克福德街三间小店合成一条可按各店名触发的街区地点。
- 所有地点GREEN统一`<地点:名称>`＋`介绍:`＋`</地点:名称>`。正文仅承担稳定环境、设施、地理功能与场所氛围；没有固定NPC出场表、剧情导演、能力数值或自动剧情解锁。
- `enabled=true`、`constant=false`、`selective=true`、`use_regex=false`，双重防递归均启用。关键词优先取具体专名，少用通用词。原九篇BLUE与54条组织/机制GREEN不动；角色认知及剧情发展依旧由咩咩全栈已封版时间线承载。
- **仅完成源码与静态装配元数据**；尚未组装CCV3或验证Android酒馆实机。精确建筑造型的全面官方逐图核实尚未完成。
