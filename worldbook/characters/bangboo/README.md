# 邦布人物条目｜bangboo-chara-v1
本分区属于咩咩制卡包·全栈的**人物层**，不是能力层，也不是新的蓝灯/绿灯。沿用 `<名字character>` 外壳、12项固定资料、四项心理模型和三句中文对话范例。

## 12项固定字段（顺序固定）
名字／类型／归属／印象／机壳配色／耳状部件／电子面屏／体型与质感／装束／机体配件／行走姿态／发声与交流。

## 邦布特有纪律
- 不强行套用人类的性别、发色、发型、胸部、鞋子或身高体重；邦布无须罩杯或三围。
- 性格采用 `Behavior / Defense / Trigger / Need` 四槽；不为每只可爱邦布虚构创伤史。
- 一般邦布是头身圆鼓、短手短脚、双足直立的小型智能机器人；一对耳状件是机械结构，不是活兔耳。脸是整块深色电子屏，不长真实兔嘴、鼻吻、胡须、动物皮毛，不以四肢着地蹦跳。
- 机体装束依型号差异变化；没有证实的精确尺寸、技能倍率和复杂履历不要写进人物正文。
- 普通邦布以「嗯呐」「嗯呐嗯呐」等短音节直接发声，少量「嗯呢」等为变体。电子面屏、动作、翻译器字幕与中文译文不等同开口说人话；只有特殊机体可能独立使用人类语言，伊埃斯H.D.D.发出的人声则属于远程通讯。
- 机载装备可在「机体配件」和「印象」内简述功能，不新建专属 `ABILITY` 文件。不要将 `S/A` 游戏抽取评级当成机体世界内的身份等级。
- 官方与原创严格分目录，不把原创故事冒称原作剧情。原创仅作日常同伴，不改动已封版时间线及官设人物关系。
- 仅在含该邦布**完整名字**的 `<story_scene>` 内匹配，避免单字触发；计划装配为 `enabled=true`、`constant=false`、`selective=true`、`use_regex=true`、`position=after_char`、双重防递归。
- 已存在的「缄枢」保留原人物文件位置、不新建重复角色；其能力核心简述已经合并入人物条目，历史 `ABILITY-064` 文件保留供追溯，**正式装配时必须排除**。
