## 安全分层与触发规则

所有组织GREEN只包含组织性质、稳定业务、与其他部门的界限和公开活动；私密成员经历、历史案件结果、具体阴谋、过往兵装、3.1—3.3后期知情及阶段性胜负，继续由人物、能力与29份时间线控制。尤其是称颂会、达识结社没有以普通关键词公开全部秘密；黑枝是**TOPS审查机构**而非政府治安局；都市秩序部属于**治安局体系**；罗斯凯利法中枢五局分工不相互混同。

新GREEN采用`enabled=true`、`constant=false`、`selective=true`、`use_regex=false`、`position=after_char`，每条有`exclude_recursion=true`和`prevent_recursion=true`。旧31条insertion_order=302—332不动，新增11条为333—343。提到「达雅特的盟约」会按官方英文Covenant of Dayat对应中文「达识结社」触发同一条，不创造第二组织。
