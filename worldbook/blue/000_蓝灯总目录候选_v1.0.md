## 全局分层规则
- 每条蓝灯只写内世界、长期有效、必要且简短的事实；不写施工指令、剧情导演术语、游戏版本 if 分支或动态变量。
- 一个设定有专属细节、角色/地点/事件依赖时，进入绿灯或其对应独立层，而非蓝灯全局注入。
- 这是**单一世界的连续剧情**：新艾利都与后续罗斯凯利法章节是时间阶段，不是 1.0 / 3.0 可切换的平行世界。
- 世界书静态条目依旧支持**常驻蓝灯 + 按关键词绿灯 + 双重防递归 + 分卷开关**，不依赖已取消的原卡脚本。
- **铃寄宿是世界线真相，不代表一开局所有 NPC 都知晓。** 剧情解锁、角色认知、能力觉醒由时间线控制，不得提前剧透或让能力超前生效。
- 具体日期仅在时间线记录中使用 `YYYY年MM月DD日` 锚点；官方未证实的日期明确标为卡内编年，不把原卡初始化的 2077-03-15 当官方纪年。
- 原卡二创附加内容必须标来源等级为**官方已证实 / 本卡改编且已确定 / 待查**。未经审查的城区、人口比例、种族、组织等不可直接升级为常驻事实。

地点分区另由 **LOCATION-BLUE-00** 单条地点总蓝灯负责，待地点模块再写正文；不是 BLUE-01 的分区列表，详见 [007](../../docs/007_地点模块一条总蓝灯_分层方案_v1.0.md)。
